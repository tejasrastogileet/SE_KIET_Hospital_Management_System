# Hospital Management System (HMS)

## Software Engineering Lab Assignments

This repository contains the Software Engineering laboratory assignments for the Hospital Management System (HMS), developed as part of the B.Tech Computer Science and Engineering curriculum at KIET Group of Institutions, Ghaziabad.

## Project Overview

The Hospital Management System is a web-based client-server application designed to automate hospital operations, including patient registration, appointment management, doctor management, admission and discharge, bed allocation, billing, pharmacy, laboratory management, and report generation.

## Objectives

- Automate routine hospital operations.
- Maintain patient and medical records.
- Manage appointments and doctor schedules.
- Handle patient admission, discharge, and bed allocation.
- Generate bills and record payments.
- Manage pharmacy inventory and laboratory tests.
- Generate hospital management reports.

## Suggested Technology Stack

- **Frontend:** HTML, CSS, JavaScript / React
- **Backend:** Java Spring Boot / PHP Laravel / Python
- **Database:** MySQL / PostgreSQL
- **Communication:** REST APIs, HTTPS, JSON

## Scope

The system covers patient registration, appointment booking, doctor management, admission and discharge, bed allocation, billing and payment, pharmacy, laboratory, and management reports.

Telemedicine, direct insurance claim processing, and medical device/IoT integration are outside the scope of this project.
